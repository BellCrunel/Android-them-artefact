# Artefact Launcher

Android-лаунчер на Kotlin + Jetpack Compose у стилі мінімалістичного списку:
великі цифри годинника, рядок «дата · погода», вертикальний список додатків
і алфавітний скрол у шухляді. Зовнішній вигляд повністю задається темою (`.ltheme`).

## Що вміє

- **Домашній екран** — заголовок із великими цифрами часу, під ним дата й погода,
  далі вертикальний список: іконка ліворуч, назва праворуч.
- **Шухляда додатків** — свайп угору, пошук, алфавітний скрол A–Z справа з бульбашкою літери.
- **Папки** — розкриваються прямо в списку, додатки додаються з шухляди.
- **Віджети** — системний пікер, віджет стає рядком на всю ширину.
- **Погода** — Open-Meteo, без ключа API. Місце шукається по ланцюжку:
  геолокація → координати вписаного міста → назва міста → **часовий пояс пристрою**
  («Europe/Kyiv» → Kyiv). Тому погода з'являється навіть без жодного дозволу.
  Кеш 30 хв, повторні спроби щохвилини, поки не вийде.
- **Жести** — свайп угору / вниз / вниз двома пальцями, кожен налаштовується.
- **Теми** — три вбудовані (Aurora, Mono Paper, Violet Dusk) + імпорт власних `.ltheme`.
- **Екран «Вигляд»** — тема, фон, шпалери, іконки й шрифт зібрані в одному місці
  з живим передпереглядом домашнього екрана вгорі. Вкладки: Тема · Фон · Іконки · Текст.
- **Стилі іконок** — 8 вбудованих (без обробки, круглі, squircle, плитки, камінці,
  скло, монохром, як у темі). Вони перемальовують системну іконку, тож працюють
  для будь-якого додатка. Сторонні паки з Play Market підхоплюються автоматично
  й з'являються поруч у списку «Папка іконок».

## Формат тем

Повний опис — [`docs/THEME_FORMAT.md`](docs/THEME_FORMAT.md). Тема керує:

- кольорами (Material 3 світла/темна схема + окремі кольори підписів і скролу);
- шпалерами — зображення або градієнт, з паралаксом при скролі;
- шрифтами — окремо для тексту й для цифр годинника;
- заголовком — стиль (`bigDigits` / `compact` / `none`), розмір і товщина цифр,
  міжлітерний інтервал, роздільник (`1041` чи `10:41`), формат дати, показ погоди;
- іконками — форма (`circle`, `squircle`, `rounded`, `hexagon`, `original`…), масштаб,
  підкладка, монохромний тінт, власні PNG або встановлений icon pack;
- списком — розмір іконки, відстані, вирівнювання, розмір і товщина назв,
  вмикання алфавітного скролу.

Шаблон для власної теми — у папці [`sample-theme/`](sample-theme).

## Збірка

### GitHub Actions (без встановлення Android Studio)

> **Спершу перемістіть файл workflow.** У корені лежить `ci-android-workflow.yml`.
> Створіть папку `.github\workflows\` і перенесіть його туди під назвою `android.yml`:
>
> ```
> F:\ANDOIRD APP\.github\workflows\android.yml
> ```
>
> (папка `.github` захищена від запису ззовні, тому файл лежить у корені)

1. Створіть репозиторій на GitHub і залийте туди цю папку:

   ```bash
   git init
   git add .
   git commit -m "Artefact Launcher"
   git branch -M main
   git remote add origin https://github.com/<ваш-нік>/bell-launcher.git
   git push -u origin main
   ```

2. Вкладка **Actions** — workflow `Build APK` запуститься автоматично.
3. Завантажте артефакт **BellLauncher-debug-apk** — усередині `BellLauncher-debug.apk`.
4. Перекиньте APK на телефон і встановіть (дозвольте встановлення з невідомих джерел).

Workflow можна запустити й вручну: **Actions → Build APK → Run workflow**.

### Локально (Android Studio)

Відкрийте папку як проєкт, дочекайтесь синхронізації Gradle, натисніть Run.
AGP 8.7.3, Kotlin 2.0.21, Gradle 8.10.2, JDK 17, compileSdk 35, minSdk 26.

## Як зробити лаунчер основним

**Налаштування Android → Додатки → Стандартні додатки → Головний екран → Artefact Launcher.**
Або натисніть «Додому» — система запропонує вибір.

## Керування

| Дія | Результат |
|---|---|
| Свайп угору | Шухляда додатків |
| Свайп вниз | Шторка сповіщень |
| Свайп вниз двома пальцями | Налаштування лаунчера |
| Довгий тап по вільному місцю | Меню: Віджети / Шпалери / Теми / Налаштування |
| Довгий тап по рядку | Меню рядка: вгору, вниз, перейменувати, створити папку, прибрати |
| Тап по папці | Розгорнути / згорнути |
| Тап по літері справа в шухляді | Перейти до додатків на цю літеру |

## Структура проєкту

```
app/src/main/java/com/bell/launcher/
├── LauncherApp.kt          контейнер залежностей
├── MainActivity.kt         HOME-activity, дозволи, імпорт тем
├── data/
│   ├── AppRepository.kt    список додатків (LauncherApps)
│   ├── LayoutRepository.kt  домашній список у layout.json
│   ├── SettingsRepository.kt
│   ├── WeatherRepository.kt Open-Meteo + геокодування міста
│   └── model/              AppInfo, HomeEntry (app / folder / widget)
├── theme/
│   ├── ThemeRepository.kt  пошук, імпорт zip, видалення тем
│   ├── ThemeSource.kt      assets або розпакована папка
│   ├── FontResolver.kt     шрифти теми (з копіюванням з assets)
│   ├── IconLoader.kt       пайплайн іконок + кеш
│   ├── IconRenderer.kt     форми, підкладки, тінт
│   ├── IconPackLoader.kt   ADW/Nova icon packs
│   ├── LauncherTheme.kt    Compose-тема з manifest.json
│   └── model/ThemeManifest.kt   схема формату v2
└── ui/
    ├── LauncherRoot.kt     складання екранів, діалоги, жести
    ├── LauncherViewModel.kt
    ├── home/               ClockHeader, список, папки, віджети
    ├── drawer/             шухляда + алфавітний скрол
    ├── settings/           налаштування, галерея тем, приховані додатки
    ├── widget/             AppWidgetHost
    ├── gestures/           не-споживаючий спостерігач жестів
    └── components/         AppRow, іконки, шпалери, AlphabetScrubber
```

## Наступні кроки (ідеї)

- Перетягування рядків для зміни порядку (зараз — пункти «Вгору/Вниз» у меню).
- Додаткові стилі заголовка: контурне слово `M O N`, `Mon.` з крапкою, рукописний.
- Каталог тем із мережі (`themes.json` за URL).
- Розмиття фону шухляди через `RenderEffect` (API 31+).
- Ярлики (shortcuts) і бейджі сповіщень.
