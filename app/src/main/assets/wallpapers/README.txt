ПАПКА ДЛЯ ВАШИХ ШПАЛЕР
======================

Покладіть сюди зображення — вони з'являться в лаунчері:
Налаштування → Вигляд → Шпалери лаунчера.

Що можна класти
---------------
* .jpg, .jpeg, .png, .webp
* Назва файлу — будь-яка латиницею або цифрами, без пробілів.
  Приклад: forest-night.jpg, gradient_01.png
* Назва без розширення стає підписом у галереї:
  "forest-night.jpg" → "forest night"

Рекомендований розмір
---------------------
1080x2400 або 1440x3200 (вертикальні, під екран телефона).
Менші теж працюють, але будуть розтягнуті.

Розмір файлу
------------
Кожне зображення потрапляє всередину APK, тому 10 картинок по 3 МБ
додадуть 30 МБ до розміру застосунку. Оптимально — до 500 КБ на файл
(стисніть JPG на 80% якості).

Після додавання
---------------
Запустіть PUSH.bat — зображення поїдуть у збірку разом із кодом.

Цей файл README.txt лаунчер ігнорує, можете його не видаляти.
