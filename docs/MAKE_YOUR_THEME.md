# Як зробити свою тему

Коротка практична інструкція. Повний перелік полів — у `THEME_FORMAT.md`.

## Що можна змінити без файлів, прямо в лаунчері

Довгий тап по вільному місцю → **Налаштування**:

| Що | Де |
|---|---|
| Які додатки в списку | Головний екран → Обрані додатки |
| `14:33` / `1433` / `14 33` | Головний екран → Формат часу |
| Шпалери телефона чи фон із теми | Вигляд → Фон лаунчера |
| Шрифт (9 варіантів) | Вигляд → Шрифт |
| Форма іконок | Іконки → Стиль іконок |
| Пак іконок із Play Market | Іконки → Пак іконок |
| Розмір іконок | Іконки → Розмір іконок |

Налаштування **сильніші за тему**: якщо ви обрали стиль іконок або шрифт вручну,
тема на це вже не впливає. Щоб повернути керування темі — виберіть «Як у темі».

---

## 1. Своя тема

Тема — це папка з `manifest.json`, запакована в ZIP.

**Найшвидший старт:** візьміть папку `sample-theme` з проєкту, змініть у `manifest.json`
поля `id`, `name` і кольори, запакуйте, імпортуйте.

```
my-theme/
├── manifest.json      ← обов'язковий
├── preview.png        ← мініатюра для галереї (опційно)
├── wallpaper.jpg      ← фон (опційно)
├── fonts/Clock.ttf    ← шрифт (опційно)
└── icons/             ← свої іконки (опційно)
```

Пакування:
- **Windows:** виділити **вміст** папки (не саму папку) → правою кнопкою →
  «Надіслати → Стиснута ZIP-папка». Можна перейменувати `.zip` на `.ltheme`.
- **Linux/Mac:** `cd my-theme && zip -r ../my-theme.ltheme .`

Встановлення: довгий тап по вільному місцю → **Теми → Імпорт** → обрати файл.

⚠️ `id` має бути унікальним. Тема з таким самим `id` перезапише попередню.

## 2. Свої іконки

### Варіант А — готовий пак із Play Market (найпростіше)

Встановіть будь-який icon pack (шукайте «icon pack»), далі
**Налаштування → Іконки → Пак іконок** — він з'явиться у списку.
Працюють паки у форматі ADW/Nova, а це майже всі.

### Варіант Б — свої PNG у темі

Створіть у темі папку `icons/` і покладіть файли, названі за package name додатка:

```
icons/
├── com.android.chrome.png
├── com.google.android.youtube.png
└── com.spotify.music.png
```

- Розмір: **192×192** або 256×256, PNG із прозорим фоном.
- Package name видно в URL Play Market:
  `play.google.com/store/apps/details?id=` **`com.spotify.music`**

Якщо назва файлу не збігається з package name, пропишіть відповідність вручну:

```json
"icons": {
  "map": { "com.android.chrome": "icons/my-chrome.png" }
}
```

Для додатків, яким ви іконку не намалювали, береться системна і до неї
застосовується форма й підкладка з теми — вигляд лишається цілісним.

## 3. Задній фон

**Три способи, від простого:**

1. **Шпалери телефона.** Налаштування → Вигляд → Фон лаунчера → «Системні шпалери».
   Лаунчер стає прозорим, видно звичайні шпалери Android. Змінити їх —
   там же кнопка «Змінити шпалери системи».

2. **Градієнт у темі** — без жодних картинок:
   ```json
   "wallpaper": {
     "gradient": ["#2B1055", "#5A2A72", "#FF9A5A"],
     "dim": 0.1
   }
   ```
   Кольори йдуть згори вниз, скільки завгодно.

3. **Своє зображення в темі.** Покладіть `wallpaper.jpg` у корінь теми:
   ```json
   "wallpaper": {
     "image": "wallpaper.jpg",
     "dim": 0.25,
     "parallaxOnScroll": true
   }
   ```
   `dim` — затемнення 0…1, щоб текст читався. `parallaxOnScroll` — фон трохи
   зсувається при прокручуванні списку.

Щоб побачити фон із теми, у Налаштуваннях має бути обрано «Фон із теми».

## 4. Стиль значків у списку

Це секція `icons` + `layout` у `manifest.json`.

**Плитки** (іконка на кольоровому квадраті):
```json
"icons": { "shape": "rounded", "cornerRadiusPercent": 30, "scale": 0.6, "background": "#1E1E28" }
```

**Круглі:**
```json
"icons": { "shape": "circle", "scale": 0.94, "background": "#FFF3E0" }
```

**Монохромні контурні** (як на других скрінах):
```json
"icons": { "shape": "original", "scale": 0.92, "background": null, "tint": "#FFFFFF" }
```

**Шестикутні / краплею / squircle:** `"shape": "hexagon" | "teardrop" | "squircle"`.

Розміри й відступи самого рядка:
```json
"layout": {
  "iconSizeDp": 44,        // розмір іконки
  "iconGapDp": 20,         // відстань від іконки до назви
  "rowSpacingDp": 12,      // відстань між рядками
  "horizontalPaddingDp": 26,
  "labelSizeSp": 17,
  "labelWeight": 500,      // 100..900
  "align": "start",        // або "center"
  "showIcons": true        // false = суто текстовий список
}
```

Заголовок із годинником:
```json
"header": {
  "style": "bigDigits",          // або "compact" / "none"
  "clockSizeSp": 82,
  "clockWeight": 700,
  "clockLetterSpacingEm": -0.06, // від'ємне стискає цифри
  "clockSeparator": ":",
  "dateFormat": "EEE, d MMM",
  "showWeather": true,
  "align": "start"
}
```

## Порада

Робіть зміни маленькими кроками й перевіряйте: якщо `manifest.json` містить
помилку (зайва кома, незакриті лапки), тема просто не з'явиться в галереї —
без повідомлення. Перевірити JSON можна будь-яким онлайн-валідатором.
